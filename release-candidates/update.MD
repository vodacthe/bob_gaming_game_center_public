- Sửa lỗi đồng bộ Google Drive tạo trùng file save khi upload và bỏ qua không tải file về nhưng vẫn báo thành công (`_list_folder_recursive` nay lưu đầy đủ file ID, tự chọn bản `modifiedTime` mới nhất, cập nhật ghi đè đúng file ID, tự dọn bản sao trùng cũ, tải nguyên tử qua `.bobtmp` và báo lỗi thật nếu thiếu file trên Drive).
- Sửa lỗi không phát hiện bản save mới nằm trong thư mục con trên Google Drive (`get_remote_modified_time` quét đệ quy toàn bộ thư mục `saves/`).
- Đảo thứ tự đồng bộ tải về: chỉ xóa file thừa ở local sau khi tải thành công từ Cloud để tránh mất dữ liệu khi lỗi mạng.
- Sửa lỗi lệch thư mục save giữa Windows và Steam Deck đối với game portable Unreal/Ludusavi (như Phantom Blade Zero): mở rộng template `<base>`/`<root>` trên SteamOS kể cả khi chưa có Proton prefix, neo đúng thư mục con khi dịch đường dẫn giữa 2 máy và ưu tiên khớp đường dẫn `cloud_peer`.
